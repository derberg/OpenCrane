# MCP Server Auth Implementation Plan (FastMCP + local/oauth + scope authz)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax. Spec: `docs/superpowers/specs/2026-07-01-mcp-auth-design.md`.

**Goal:** Add MCP-spec-compliant auth to the OpenCrane MCP HTTP server — `local` mode (self-hosted OAuth AS with a browser login form) and `oauth` mode (external-IdP resource server) — plus declarative scope→source content authorization, by migrating the HTTP transport to FastMCP.

**Architecture:** FastMCP hosts the HTTP transport. Existing tools are registered via a bridge that preserves their hand-built JSON schemas and `(arguments: dict) -> list[TextContent]` handlers. Auth is selected by `config.yaml`'s `auth:` block: `none` (open), `local` (`auth_server_provider`), `oauth` (`token_verifier`). Scopes on the validated `AccessToken` map to allowed `source_name`s, AND-ed into both search backends.

**Tech Stack:** Python 3.11+, `mcp==1.28.*` (FastMCP + `mcp.server.auth`), Starlette, PyJWT (`[auth]` extra), pytest.

## Global Constraints

- Python >= 3.11. Run tests ONLY via `./pytest.sh` (from the worktree). Never call `pytest` directly.
- **100% coverage** (`./pytest.sh --check-coverage`). Every new line tested; `# pragma: no cover` only for genuinely-unreachable defensive branches, matching existing style.
- **Never modify existing tests** without explicit user confirmation. If an existing test fails during the FastMCP migration, STOP and report — do not "fix" it by changing it.
- Test isolation: `tmp_path`/`monkeypatch` only; never touch `.opencrane/` or production paths.
- Commits: `type: short description`, NO AI co-author attribution.
- Secrets from env only. **Fail closed** on any auth misconfig (raise at startup/parse).
- **Security invariant:** an empty allowlist (`[]`) means zero permitted sources and MUST short-circuit to no results — never pass `[]` to a backend (`if source_names:` is falsy for `[]`, which disables filtering and leaks everything).
- **Pin the SDK:** `mcp>=1.28,<1.29` in `pyproject.toml`; the tool bridge uses SDK internals verified only for 1.28.x.

## Phases

- **Phase 1 — Foundations** (Tasks 1–2): config parsing + access policies. Pure, no SDK. Independently valuable.
- **Phase 2 — FastMCP migration** (Task 3): move HTTP transport to FastMCP with no auth; all existing behavior preserved; smoke test. **Highest risk — verify green before proceeding.**
- **Phase 3 — Layer-2 enforcement** (Task 4): constrain search by scopes (tested with a mocked token).
- **Phase 4 — `local` mode** (Tasks 5–6): self-hosted AS provider + login form + wiring.
- **Phase 5 — `oauth` mode** (Task 7): JWT verifier + `[auth]` extra + wiring.
- **Phase 6 — Docs** (Task 8).

Each task ends green + committed. After Phase 2, run the FULL existing suite (`./pytest.sh`) and confirm no regressions before continuing.

### Task 2: Access policies (Phase 1)

**Files:** Create `opencrane/mcp/auth/policies.py`; Test `tests/unit/mcp/auth/test_policies.py`.

**Produces:**
- `class AllowAllPolicy`: `authorize(scopes: tuple[str,...], requested: list[str]|None) -> list[str]|None` → returns `requested` unchanged (None or list).
- `class ScopeSourcesPolicy(scope_sources, default_sources)`: `allowed = union(scope_sources[s] for s in scopes)`; no match ⇒ `set(default_sources)`; if `requested`: `sorted(s for s in requested if s in allowed)`; else `sorted(allowed)`. Always a concrete list.

**New `http_server.py` core:**

```python
from mcp.server.fastmcp import FastMCP
from mcp.server.fastmcp.tools.base import Tool
from mcp.server.fastmcp.utilities.func_metadata import FuncMetadata, ArgModelBase
from pydantic import ConfigDict

class _PassthroughArgModel(ArgModelBase):
    model_config = ConfigDict(extra="allow")
    def model_dump_one_level(self):
        return {"arguments": dict(self.__pydantic_extra__ or {})}

def _register(mcp, name, description, input_schema, handler):
    mcp._tool_manager._tools[name] = Tool(
        fn=handler, name=name, title=None, description=description,
        parameters=input_schema,
        fn_metadata=FuncMetadata(arg_model=_PassthroughArgModel),
        is_async=True, context_kwarg=None, annotations=None,
    )

def _register_tools(mcp):
    from opencrane.mcp import server as s
    _register(mcp, "search_docs", s._build_search_tool().description,
              s._build_search_tool().inputSchema, s.search_docs)
    _register(mcp, "health", "Check the health of the documentation search service",
              {"type": "object", "properties": {}, "required": []}, s.health_check)
    if s._has_list_item_chunks():
        _register(mcp, "get_list_members", <desc from server.list_tools>, <schema>, s.get_list_members)
    if s._has_yaml_chunks():
        _register(mcp, "get_yaml_definition", <desc>, <schema>, s.get_yaml_definition)
    if s._has_yaml_chunks() or s._has_list_item_chunks():
        _register(mcp, "get_metadata_schema", <desc>, <schema>, s.get_metadata_schema)

def build_app():
    mcp = FastMCP("opencrane", stateless_http=True, json_response=False,
                  lifespan=_lifespan)  # _lifespan calls init_services()
    _register_tools(mcp)
    @mcp.custom_route("/health", methods=["GET"])
    async def _health(request):
        ...  # existing health_handler body (open, unauthenticated)
    return mcp

def get_app():  # module-level app used by main()
    ...
```

**Behavior:** read scopes from the SDK access token, resolve the policy, constrain `source_names`, short-circuit empty.
```python
    source_names = arguments.get("source_names")
    # --- Layer 2: content authorization ---
    from opencrane.mcp.auth.runtime import current_scopes, get_access_policy
    policy = get_access_policy()
    decision = policy.authorize(current_scopes(), source_names)
    if decision is not None and len(decision) == 0:
        logger.info("   🔒 search: no sources permitted for this caller")
        return [TextContent(type="text", text="No results found.")]
    source_names = decision
    # --------------------------------------
```
**New `opencrane/mcp/auth/runtime.py`:**

### Task 5: `local` mode — self-hosted OAuth provider + login form (Phase 4)

**Files:** Create `opencrane/mcp/auth/local_provider.py`; Test `tests/unit/mcp/auth/test_local_provider.py`. (Model closely on OpenCollective's `OCAuthProvider` — see `/Users/derberg/Documents/GitHub/opencollective-mcp/mcp_for_ocp_graphql/auth.py`.)

**Produces:**
- `verify_credentials(*, method, submitted) -> tuple[bool, tuple[str,...]]`: for `method="token"`, `submitted` is the pasted token; accept iff it matches any of `OPENCRANE_ACCESS_TOKEN` (comma-split; `secrets.compare_digest`); for `password`, `submitted` is `(user,pass)` matched against `OPENCRANE_LOGIN_USER`/`PASS`.
